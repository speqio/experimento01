# Contenido para completar las fichas de producto

Objetivo: que cada servicio tenga el formato estándar de la ficha (ver `README.md`): texto de introducción y luego **Beneficios**, **Incluye**, **Indicado para** y **Contraindicaciones**.

> **Son borradores.** Se armaron con frases que el propio spa ya usa en productos completos (por ejemplo, el texto de contraindicaciones y el cierre con "estación de autoatención"). Antes de publicar, el equipo (o un profesional de salud/estética) debe revisar los beneficios, "indicado para" y contraindicaciones de cada servicio, sobre todo en **masajes para embarazadas** y **piedras calientes**. Ajusta cada texto a lo que realmente incluye la sesión.

## Cómo pegarlo (2 minutos por producto)
1. Abre el producto con el enlace de la tabla (WordPress → Productos → editar).
2. En el editor de la **descripción larga**, cambia a la pestaña **Texto** (no "Visual").
3. Deja el texto de introducción que ya existe. Si hay una lista de precios por sesiones, puedes dejarla: la ficha la oculta sola.
4. Pega el bloque de abajo **al final**, después del texto. Solo incluye las secciones que faltan.
5. Pulsa **Actualizar**. La ficha se actualiza en el siguiente despliegue del sitio.

Regla de formato: cada sección es un párrafo con la etiqueta ("Beneficios:") seguido de una lista. No pegues texto copiado de ChatGPT o Word: pega siempre como texto sin formato.

## Productos que NO siguen el formato de servicio

Estos no llevan "Indicado para" ni "Contraindicaciones" como un masaje o facial. Se recomienda **no forzar** el formato: en la ficha se muestran como texto de introducción más cajas adicionales (por ejemplo "Modo de uso", "Ingredientes destacados"), que ya soporta el sitio.

Complementos (upgrade/extensión): una descripción corta basta; opcionalmente "Beneficios:" con dos o tres puntos.
